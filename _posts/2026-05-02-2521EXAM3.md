**Assumptions and Constraints:**
- The graph may have cycles — your solution must handle these
- 0 ≤ src, dest < nV
- You must not modify the graph
- Global and static variables are strictly forbidden

**`Graph.h`:**
```c
#ifndef GRAPH_H
#define GRAPH_H

typedef struct GraphRep *Graph;
typedef int Vertex;

struct GraphRep {
    int **edges;   // adjacency matrix: edges[u][v] = 1 if edge u->v exists
    int nV;        // number of vertices
};

Graph GraphNew(int nV);
void  GraphFree(Graph g);
void  GraphAddEdge(Graph g, Vertex u, Vertex v);
int   GraphNumVertices(Graph g);
void  GraphPrint(Graph g);

#endif
```

**`Graph.c`:**
```c
#include <stdio.h>
#include <stdlib.h>
#include "Graph.h"

Graph GraphNew(int nV) {
    Graph g = malloc(sizeof(struct GraphRep));
    g->nV = nV;
    g->edges = malloc(nV * sizeof(int *));
    for (int i = 0; i < nV; i++) {
        g->edges[i] = calloc(nV, sizeof(int));
    }
    return g;
}

void GraphFree(Graph g) {
    for (int i = 0; i < g->nV; i++) free(g->edges[i]);
    free(g->edges);
    free(g);
}

void GraphAddEdge(Graph g, Vertex u, Vertex v) {
    g->edges[u][v] = 1;
}

int GraphNumVertices(Graph g) {
    return g->nV;
}

void GraphPrint(Graph g) {
    for (int i = 0; i < g->nV; i++) {
        printf("%d: ", i);
        for (int j = 0; j < g->nV; j++)
            if (g->edges[i][j]) printf("%d ", j);
        printf("\n");
    }
}
```

# Answer Guidance

**Theory hints:**

- Q1c: Shortest path 0→4 is 0→1→3→2→4 with weight 3+1+2+4 = 10. Not 0→3→2→4 (weight 7+2+4=13) or 0→1→2→4 (weight 3+2+4=9). Actually 0→1→2→4 = 9 is shortest. Trace carefully.
- Q2c: This graph is a tree (7 vertices, 6 edges, connected). A tree never has cycles — n vertices and n-1 edges with no cycle is the definition of a tree.
- Q3a: Sorted edges: B-C(1), A-C(2), D-E(2), C-D(3), A-B(4), B-E(5), A-D(7), C-E(8). Kruskal adds: B-C, A-C, D-E, C-D. Total weight = 8.
- Q4b: Search for 36 — hash to 3, probe: 11@0, 22@1, 33@2, 25@3... wait, trace the actual insertions carefully first.
- Q5b: Counterexample — 0→1 (weight 1), 0→2 (weight 5), 1→2 (weight -4). Dijkstra picks 1 first (dist 1), then finalises 2 as dist=5 from direct edge, missing the path 0→1→2 = -3.

**Practical hints:**

- Q6: DFS with a visited array. If src == dest return 1 immediately. Otherwise mark src visited, recurse on all neighbours, return 1 if any recursive call returns 1.
- Q7: Iterate all vertices. Each time you find an unvisited vertex, run DFS from it and increment counter.
- Q8: The key insight — `visited[]` alone isn't enough for directed graphs. Need `onStack[]` to track the current DFS path. A cycle exists only if you hit a node currently on the stack.
- Q9: Insert can use a DELETED slot. Search skips DELETED but stops at EMPTY. Delete finds key using search logic then marks DELETED.
- Q10: Watch for INT_MAX overflow — before updating `dist[w] = dist[v] + weight`, check `dist[v] != INT_MAX`.
