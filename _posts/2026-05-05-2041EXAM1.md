# Question 1 (10 marks) — `grep`

**File:** `q1/practice_q1.txt`

You have been given the file:

```text
q1/movies.psv
```

This file contains information about films. Each line has six fields separated by `|`:

```text
Genre | Title | Director | Country | Year | Rating
```

Your task is to write **four grep commands** that print specified lines.

Edit `q1/practice_q1.txt` and place each answer after the corresponding `"Answer N:"` line.

Each answer must be a **SINGLE grep command**.

You may **not** use:

* pipes
* `sed`
* `awk`
* any other command

You may use any `grep` option except:

```text
-P / --perl-regexp
```

## Question 1

Write a grep command that prints lines for films directed by an Australian director.

## Question 2

Write a grep command that prints lines for Horror films released after the year 2000.

## Question 3

Write a grep command that prints lines for films with a rating of `9.0` or above.

## Question 4

Write a grep command that prints lines where the director's first name and last name start with the same letter.

Examples:

```text
Steven Spielberg     → both start with S → match
Christopher Nolan    → C vs N            → no match
```

## Example Session

```sh
$ grep 'Australia' q1/movies.psv
Action|Mad Max: Fury Road|George Miller|Australia|2015|8.1
Comedy|Muriel's Wedding|P.J. Hogan|Australia|1994|7.1
...
```

## Commands

```sh
Submit:   give cs2041 practice_q1 practice_q1.txt
```

```text
CourseCODE|StudentID|Surname, GivenNames|Plan|Gender
```

The last field is:

* `M` (male)

In `practice_q2.sh`, write a **SINGLE shell pipeline** that:

* No `&&`, `||`, `;`

# Question 4 (9 marks) — Python

**File:** `q4/practice_q4.py`

Write a Python program `practice_q4.py` that takes one command-line argument `N` (a positive integer) and reads text from `stdin`.

It should print the `N` most frequent words in the input, one per line, in the format:

```text
word count
```

Results should be sorted:

1. Most frequent first
2. If frequencies are equal, sort alphabetically

Words are case-insensitive:

* `"The"` and `"the"` count as the same word

Strip leading/trailing punctuation from each word before counting.

## Example

```sh
$ ./practice_q4.py 5 < q4/words.txt
the 8
fox 5
dog 3
one 3
two 3
```

```sh
$ ./practice_q4.py 1 < q4/words.txt
the 8
```

## Restrictions

* Python only — no `subprocess`
* You may **NOT** use the `collections` module

## Commands

```sh
Autotest: cd q4 && sh autotest_q4.sh
Submit:   give cs2041 practice_q4 practice_q4.py
```

# Question 5 (9 marks) — Shell Script

**File:** `q5/practice_q5.sh`

Write a POSIX-compatible shell script `practice_q5.sh` that takes a single argument:
the name of a text file.

The script should print each line of the file prefixed with its line number in the format:

```text
N: line content
```

where `N` starts at `1`.

## Example

```sh
$ ./practice_q5.sh q5/hamlet.txt
1: To be or not to be that is the question
2: Whether tis nobler in the mind to suffer
3: The slings and arrows of outrageous fortune
...
```

```sh
$ echo "hello" | ./practice_q5.sh /dev/stdin
1: hello
```

## Restrictions

* POSIX shell (`/bin/dash`) only
* You may **NOT** use:

  * `awk`
  * Python
  * Perl
  * `cat -n`
  * `nl`
* You may **NOT** use temporary files
* You **must** use a `while/read` loop

### Permitted External Programs

* `cat`
* `echo`
* `expr`
* `grep`
* `head`
* `sed`
* `tail`
* `wc`

# Question 6 (9 marks) — Python

**File:** `q6/practice_q6.py`

Write a Python program `practice_q6.py` that takes one command-line argument:
the path to a CSV file in this format (with header row):

```text
name,age,grade,score
```

where `grade` is one of:

```text
HD, DN, CR, PS, FL
```

The program should print:

* The count of students achieving each grade (`HD`, `DN`, `CR`, `PS`) in that order
* The average score across **ALL** students, formatted to `2` decimal places

## Example

```sh
$ ./practice_q6.py q6/students.csv
HD: 3
DN: 2
CR: 2
PS: 1
Average score: 76.25
```

## Notes

* The header line should be skipped
* `FL` (fail) should not be printed in the grade counts
* Average is computed over all students regardless of grade
* You can assume the file is well-formed

## Restrictions

* Python only — no `subprocess`
* You may **NOT** use the `csv` module

## Commands

```sh
Autotest: cd q6 && sh autotest_q6.sh
Submit:   give cs2041 practice_q6 practice_q6.py
```
