#define QUEUE_H

typedef struct QueueRep *Queue;

**`Queue.c`:**
```c
#include <stdio.h>
#include <stdlib.h>
#include "Queue.h"

struct QueueNode {
    int val;
    struct QueueNode *next;
};

struct QueueRep {
    struct QueueNode *head;
    struct QueueNode *tail;
};

Queue QueueNew(void) {
    Queue q = malloc(sizeof(struct QueueRep));
    q->head = q->tail = NULL;
    return q;
}

void QueueFree(Queue q) {
    struct QueueNode *curr = q->head;
    while (curr != NULL) {
        struct QueueNode *next = curr->next;
        free(curr);
        curr = next;
    }
    free(q);
}

void QueueEnqueue(Queue q, int val) {
    struct QueueNode *n = malloc(sizeof(struct QueueNode));
    n->val  = val;
    n->next = NULL;
    if (q->tail == NULL) {
        q->head = q->tail = n;
    } else {
        q->tail->next = n;
        q->tail = n;
    }
}

int QueueDequeue(Queue q) {
    if (q->head == NULL) {
        fprintf(stderr, "error: dequeue from empty queue\n");
        exit(1);
    }
    struct QueueNode *n = q->head;
    int val = n->val;
    q->head = n->next;
    if (q->head == NULL) q->tail = NULL;
    free(n);
    return val;
}

int QueueIsEmpty(Queue q) {
    return q->head == NULL;
}
```

# Answer Guidance

**Theory:**

- Q1a: fnA — outer loop O(n), inner loop starts at i and doubles so O(log n) iterations → O(n log n). fnB — three recursive calls each with n/3, plus O(n) work. Recurrence T(n) = 3T(n/3) + O(n) → O(n log n) by master theorem.
- Q2b: Already-sorted input `[1,2,3,4,5,6]` — quicksort last-element pivot is O(n²). Merge sort is always O(n log n).
- Q3d: Insert 22 — goes left of 25. Check BFs — no violation. Insert 28 — goes right of 25, left of 30. BF(30) = 2, taller child is 25, 25 is right-heavy → RL case.
- Q4d: Dijkstra finalises vertex 1 with dist=5 via 0→1. But 0→2→1 = 3+(-2) = 1, which is shorter. Since 1 is already finalised, Dijkstra never updates it.
- Q5c: Trie wins on prefix search easily. Hash table requires scanning all 2 million words for prefix queries.

**Practical:**

- Q6: NULL → 0. Leaf (both children NULL) → return node value. Otherwise → sumLeaves(left) + sumLeaves(right).
- Q7: BFS with a dist[] array initialised to -1. Set dist[src]=0, enqueue src. When dequeuing v, for each neighbour w: if dist[w]==-1, set dist[w]=dist[v]+1, enqueue. Return dist[dest].
- Q8: If both a and b < t->value → go left. If both > t->value → go right. Otherwise current node is the LCA — return t->value.
- Q9: BFS from each vertex tracking dist[] and parent[]. When you find neighbour w that is visited and w != parent[curr], cycle length = dist[curr] + dist[w] + 1.
- Q10: The key insight — a max-heap of the smallest (n/2)+1 elements has the median at its root. Any new element smaller than the current max displaces it.
