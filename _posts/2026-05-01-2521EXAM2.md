## `bst.h`

```c
#ifndef BST_H
#define BST_H

// The node structure for the BST
struct node {
    int value;
    struct node *left;
    struct node *right;
};

// Creates and returns a new node with the given value
struct node *newNode(int value);

// Inserts a value into the BST and returns the root
struct node *bstInsert(struct node *t, int value);

// Searches for a value in the BST
// Returns 1 if found, 0 otherwise
int bstSearch(struct node *t, int value);

// Frees all memory associated with the BST
void bstFree(struct node *t);

// Prints the BST in-order
void bstPrint(struct node *t);

#endif
```

---

## `bst.c`

```c
#include <stdio.h>
#include <stdlib.h>
#include "bst.h"

struct node *newNode(int value) {
    struct node *n = malloc(sizeof(struct node));
    if (n == NULL) {
        fprintf(stderr, "error: out of memory\n");
        exit(1);
    }
    n->value = value;
    n->left  = NULL;
    n->right = NULL;
    return n;
}

struct node *bstInsert(struct node *t, int value) {
    if (t == NULL) return newNode(value);
    if (value < t->value)
        t->left  = bstInsert(t->left,  value);
    else if (value > t->value)
        t->right = bstInsert(t->right, value);
    // duplicate values are ignored
    return t;
}

int bstSearch(struct node *t, int value) {
    if (t == NULL)          return 0;
    if (value == t->value)  return 1;
    if (value < t->value)   return bstSearch(t->left,  value);
    return                         bstSearch(t->right, value);
}

void bstFree(struct node *t) {
    if (t == NULL) return;
    bstFree(t->left);
    bstFree(t->right);
    free(t);
}

void bstPrint(struct node *t) {
    if (t == NULL) return;
    bstPrint(t->left);
    printf("%d ", t->value);
    bstPrint(t->right);
}
```

# Answer Guidance (check your own work)

**Theory hints:**

- Q1b: Deleting 30 — it has two children. In-order successor is 35 (leftmost in right subtree). Copy 35 into 30's position, delete original 35 node (which is a leaf — easy).
- Q2b: The answer is **A**. Post-order visits left subtree, then right subtree, then root. The root (15) must be last — all options have this. Then check the left subtree `3, 10, 12, 7` — in post-order the left subtree root (7) must come last in that group, which rules out D. Then within 7's subtrees: 3 is alone on the left (correct in A), and 10 then 12 are right subtree of 7 where 12 is the root — post-order gives 10 then 12 ✓.
- Q3a: After inserting 10, 20 (RR → left rotate), 30: then insert 25 (goes right of 20, left of 30 — no violation yet), then 28 (RL case at 30 — right rotate at 25, left rotate at 30).
- Q5c: Always pick the middle element of the current subarray as root, recurse on left and right halves. O(n) time since you visit each element once.

**Practical hints:**

- Q6: Base case NULL → return -1. Otherwise return `1 + max(height(left), height(right))`.
- Q7: Base case NULL → 0. If level == 0 → return node's value. Otherwise return `levelSum(left, level-1) + levelSum(right, level-1)`.
- Q8: O(h) solution — at each node, compare current node to best so far and use BST property to decide which subtree to explore, not both.
- Q9: If node value < lo, all valid nodes must be in the right subtree — return `trim(t->right, lo, hi)`. If node value > hi, return `trim(t->left, lo, hi)`. Otherwise recurse on both children.
- Q10: Step 1 — in-order traversal into an array O(n). Step 2 — build balanced BST from sorted array by always picking the middle as root, recursing on left and right halves O(n). Total O(n).
