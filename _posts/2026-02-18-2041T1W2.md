## `head`

Displays the first N lines of input. Default is 10 lines if no option is given.

bash

```bash
head file.txt          # first 10 lines
head -n 3 file.txt     # first 3 lines
head -3 file.txt       # shorthand for -n 3
head -c 100 file.txt   # first 100 bytes
```

**Options glossary:**

|Option|Meaning|
|---|---|
|`-n N`|Print the first N lines (default: 10)|
|`-N`|Shorthand for `-n N`|
|`-c N`|Print the first N bytes instead of lines|

---

## `tail`

Displays the last N lines of input. The mirror image of `head`.

bash

```bash
tail file.txt          # last 10 lines
tail -n 3 file.txt     # last 3 lines
tail -f file.txt       # follow file as it grows
tail -c 100 file.txt   # last 100 bytes
```

**Options glossary:**

|Option|Meaning|
|---|---|
|`-n N`|Print the last N lines (default: 10)|
|`-N`|Shorthand for `-n N`|
|`-c N`|Print the last N bytes instead of lines|
|`-f`|Follow: keep reading and printing as the file grows. Useful for monitoring log files|

## `cat`

Concatenates and prints files to stdout. Often used just to feed a file into a pipeline.

bash

```bash
cat file.txt                             # print file to stdout
cat file1.txt file2.txt                  # concatenate two files
cat file1.txt file2.txt > combined.txt   # merge into one file
cat -n file.txt                          # print with line numbers
cat -A file.txt                          # show non-printing characters
```

**Options glossary:**

|Option|Meaning|
|---|---|
|`-n`|Number all output lines|
|`-b`|Number non-blank output lines only|
|`-s`|Squeeze multiple consecutive blank lines into one|
|`-A`|Show non-printing characters; tabs shown as `^I`, end of line as `$`|
|`-v`|Show non-printing characters except tabs and end-of-line|

## `wc`

Word count — counts lines, words, and bytes in a file or stdin.

bash

```bash
wc file.txt          # lines, words, and bytes
wc -l file.txt       # lines only
wc -w file.txt       # words only
wc -c file.txt       # bytes only
wc -m file.txt       # characters only
grep 'bash' /etc/passwd | wc -l    # count lines from a pipeline
```

**Options glossary:**

|Option|Meaning|
|---|---|
|`-l`|Count lines (newline characters)|
|`-w`|Count words (whitespace-delimited tokens)|
|`-c`|Count bytes|
|`-m`|Count characters (differs from `-c` in multibyte/Unicode encodings)|
|`-L`|Print the length of the longest line|

## `grep`

Searches input and prints lines that match a pattern. One of the most used Unix tools.

bash

```bash
grep 'pattern' file.txt           # basic search
grep -E 'pattern' file.txt        # extended regex
grep -i 'pattern' file.txt        # case-insensitive
grep -v 'pattern' file.txt        # invert match
grep -n 'pattern' file.txt        # show line numbers
grep -c 'pattern' file.txt        # count matching lines
grep -r 'pattern' directory/      # search recursively
grep '^root' file.txt             # lines starting with "root"
grep 'bash$' file.txt             # lines ending with "bash"
grep -E '^(cs|se)[0-9]{4}:'       # alternation and exact repetition
```

**Options glossary:**

|Option|Meaning|
|---|---|
|`-E`|Use extended regular expressions (allows `+`, `?`, `\|`, `{n}`, `()` without backslashes)|
|`-F`|Treat pattern as a fixed string, not a regex (faster for literal searches)|
|`-i`|Case-insensitive matching|
|`-v`|Invert match: print lines that do NOT match|
|`-n`|Prefix each output line with its line number|
|`-c`|Print only a count of matching lines|
|`-l`|Print only the names of files that contain a match|
|`-L`|Print only the names of files that do NOT contain a match|
|`-r`|Recursively search directories|
|`-w`|Match whole words only|
|`-x`|Match whole lines only|
|`-A N`|Print N lines of context after each match|
|`-B N`|Print N lines of context before each match|
|`-C N`|Print N lines of context before and after each match|
|`-o`|Print only the matched portion of each line, not the whole line|
|`-q`|Quiet: produce no output, just set exit status (0 if match found)|

## `cut`

Extracts specific fields or character positions from each line.

bash

```bash
cut -d: -f1 file.txt          # field 1, colon-delimited
cut -d: -f1,2 file.txt        # fields 1 and 2
cut -d'|' -f2 file.txt        # field 2, pipe-delimited
cut -c1-5 file.txt            # characters 1 through 5
cut -c1,3,5 file.txt          # characters 1, 3, and 5
cut -d: -f3- file.txt         # field 3 through end of line
```

**Options glossary:**

|Option|Meaning|
|---|---|
|`-d delim`|Set the field delimiter (default is tab). Must be a single character|
|`-f list`|Select fields by number. `1` = first field. Supports ranges (`1-3`), lists (`1,3`), and open ranges (`2-`)|
|`-c list`|Select characters by position. Same range/list syntax as `-f`|
|`-b list`|Select bytes by position|
|`--complement`|Invert selection: print everything except the specified fields/characters|
|`-s`|Suppress lines that don't contain the delimiter (by default they are printed unchanged)|

## `sort`

Sorts lines of text. Default is alphabetical, ascending, on the whole line.

bash

```bash
sort file.txt                    # alphabetical ascending
sort -r file.txt                 # reverse/descending
sort -n file.txt                 # numeric sort
sort -rn file.txt                # numeric descending
sort -u file.txt                 # sort and remove duplicates
sort -k2,2 file.txt              # sort by field 2 only (alphabetic)
sort -k2,2n file.txt             # sort by field 2 (numeric)
sort -k2,2n -k3,3rn file.txt    # field 2 asc, tiebreak field 3 desc
sort -t'|' -k2,2n file.txt      # pipe-delimited, sort by field 2
sort -t$'\t' -k3,3n file.txt    # tab-delimited, sort by field 3
```

**Options glossary:**

| Option         | Meaning                                                                                                                                                                       |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `-n`           | Numeric sort: compare fields as numbers, not strings                                                                                                                          |
| `-r`           | Reverse: sort in descending order                                                                                                                                             |
| `-u`           | Unique: discard duplicate lines after sorting                                                                                                                                 |
| `-f`           | Fold case: treat uppercase and lowercase as equal                                                                                                                             |
| `-k pos1,pos2` | Sort using the key starting at field `pos1` and ending at `pos2`. Without `,pos2`, the key runs to end of line. Append `n`, `r`, `f` etc. directly to the key (e.g. `-k2,2n`) |
| `-t delim`     | Set field delimiter (default is whitespace). Use `$'\t'` for tab                                                                                                              |
| `-s`           | Stable sort: preserve original order of lines that compare equal                                                                                                              |
| `-b`           | Ignore leading blanks when finding sort keys                                                                                                                                  |
| `-m`           | Merge: assume input files are already sorted and merge them                                                                                                                   |
| `-c`           | Check: verify input is already sorted; report if not                                                                                                                          |
| `-o file`      | Write output to file instead of stdout (safe to use with the input file)                                                                                                      |
| `-d`           | dictionary order: ignore non-letters and non-digits                                                                                                                           |
| `-kn`          | sort on column n                                                                                                                                                              |

## `uniq`

Removes or counts consecutive duplicate lines. Must almost always be preceded by `sort` since only adjacent duplicates are detected.

bash

```bash
uniq file.txt              # remove consecutive duplicates
uniq -c file.txt           # prefix each line with occurrence count
uniq -d file.txt           # print only duplicated lines
uniq -u file.txt           # print only unique (non-duplicated) lines
uniq -i file.txt           # case-insensitive comparison
sort file.txt | uniq -c | sort -rn   # frequency count, most common first
```

**Options glossary:**

|Option|Meaning|
|---|---|
|`-c`|Prefix each output line with the number of times it occurred|
|`-d`|Only print lines that appear more than once|
|`-u`|Only print lines that appear exactly once|
|`-i`|Case-insensitive comparison|
|`-f N`|Skip the first N fields before comparing|
|`-s N`|Skip the first N characters before comparing|
|`-w N`|Compare only the first N characters of each line|

## `tr`

Translates or deletes characters. Works character by character, not on words or patterns. Reads from stdin only — no filename argument.

bash

```bash
tr 'abc' 'ABC'                    # replace a→A, b→B, c→C
tr '[:lower:]' '[:upper:]'        # uppercase everything
tr -d ' '                         # delete all spaces
tr -d '\n'                        # delete all newlines
tr -s ' '                         # squeeze runs of spaces into one
tr -cs 'a-zA-Z0-9' '\n'          # split into one word per line
tr -cs '[:alpha:]' '\n'           # same, letters only
```

**The word-splitting idiom:**

bash

```bash
tr -cs 'a-zA-Z0-9' '\n' < file.txt
```

`-c` complements the alphanumeric set (so we target everything else), and `-s` squeezes consecutive non-alphanumeric characters into a single newline. Result: one word per line.

**POSIX character classes:**

|Class|Meaning|
|---|---|
|`[:alpha:]`|All letters (a–z, A–Z)|
|`[:lower:]`|Lowercase letters|
|`[:upper:]`|Uppercase letters|
|`[:digit:]`|Digits (0–9)|
|`[:alnum:]`|Letters and digits|
|`[:space:]`|Whitespace (space, tab, newline, etc.)|
|`[:punct:]`|Punctuation characters|
|`[:print:]`|Printable characters|

**Options glossary:**

|Option|Meaning|
|---|---|
|`-d`|Delete characters in the given set; do not translate|
|`-s`|Squeeze: replace consecutive repeated characters that are in the set with a single occurrence|
|`-c`|Complement: act on all characters NOT in the given set|

Note that `-c` and `-s` can be combined: `-cs` complements first, then squeezes the complemented set after translation.

## `sed`

Stream editor — reads input line by line and applies editing commands. Most commonly used for substitution and deletion.

### Substitution

bash

```bash
sed 's/pattern/replacement/'        # replace first match per line
sed 's/pattern/replacement/g'       # replace all matches per line
sed 's/pattern/replacement/2'       # replace 2nd match only
sed 's/pattern/replacement/gi'      # global, case-insensitive
sed -E 's/0+([0-9])/\1/g'          # extended regex with capture group
sed -E 's/\t0+([0-9])/\t\1/g'      # strip leading zeroes after tabs
```
### Deletion

bash

```bash
sed '/pattern/d'                    # delete lines matching pattern
sed '3d'                            # delete line 3
sed '2,5d'                          # delete lines 2 through 5
sed '/^program[2-9]\t/d'           # delete lines starting with program2–9
```

### Address ranges

Addresses restrict which lines a command applies to. Without an address, the command applies to every line.

bash

```bash
sed '1s/foo/bar/'                   # substitute only on line 1
sed '2,10s/foo/bar/'                # substitute on lines 2–10
sed '/start/,/end/d'               # delete from line matching start to line matching end
sed '$d'                            # delete the last line
```

### Multiple commands

bash

```bash
sed -e 's/foo/bar/g' -e '/baz/d' file.txt
sed 's/foo/bar/g; /baz/d' file.txt
```

### In-place editing

bash

```bash
sed -i 's/foo/bar/g' file.txt        # modify file directly
sed -i.bak 's/foo/bar/g' file.txt    # modify, keeping .bak backup
```

**Options glossary:**

|Option|Meaning|
|---|---|
|`-E`|Use extended regular expressions (allows `+`, `?`, `|
|`-n`|Suppress automatic printing; only print when explicitly told to with `p`|
|`-e script`|Add a script/command to execute. Allows multiple commands in one call|
|`-f file`|Read sed commands from a file|
|`-i[suffix]`|Edit file in-place. If suffix given (e.g. `.bak`), a backup is created first|

**Substitution flag glossary** (the flags after the final `/` in `s/pattern/replacement/flags`):

|Flag|Meaning|
|---|---|
|`g`|Global: replace all matches on the line, not just the first|
|`N` (a number)|Replace only the Nth match on the line|
|`i`|Case-insensitive matching|
|`p`|Print the line if a substitution was made (useful with `-n`)|
|`w file`|Write lines where substitution occurred to a file|

**Common sed commands:**

|Command|Meaning|
|---|---|
|`s/pat/rep/`|Substitute|
|`d`|Delete the line|
|`p`|Print the line|
|`q`|Quit after this line|
|`y/abc/ABC/`|Transliterate characters (like `tr`)|
|`=`|Print the current line number|
|`i\text`|Insert text before the line|
|`a\text`|Append text after the line|

## `join`

Joins two files on a common field, like a database join. **Both files must be sorted on the join field first** — this is the most common mistake.

bash

```bash
join file1.txt file2.txt                          # inner join on field 1
join -t'|' file1.txt file2.txt                    # pipe-delimited
join -t'|' -a1 file1.txt file2.txt               # left outer join
join -t'|' -a2 file1.txt file2.txt               # right outer join
join -t'|' -a1 -a2 file1.txt file2.txt           # full outer join
join -t'|' -a1 -a2 -e '--' -o '0,1.2,2.2' \
     <(sort file1.txt) <(sort file2.txt)          # full outer join with fill
```

**Output format with `-o`:**

`0` refers to the join key. `1.N` refers to field N of file 1. `2.N` refers to field N of file 2. For example, `-o '0,1.2,2.2'` prints: join key, field 2 from file 1, field 2 from file 2.

**Options glossary:**

|Option|Meaning|
|---|---|
|`-t delim`|Set field delimiter (default is whitespace)|
|`-1 N`|Join on field N of file 1 (default: 1)|
|`-2 N`|Join on field N of file 2 (default: 1)|
|`-a N`|Also print unpairable lines from file N (1 or 2). Use both `-a1 -a2` for a full outer join|
|`-v N`|Like `-a N` but suppress paired lines (print only unmatched lines from file N)|
|`-e str`|Replace missing (empty) fields with `str` when used with `-a` or `-o`|
|`-o format`|Control output format. Fields specified as `0` (join key), `1.N` (field N of file 1), `2.N` (field N of file 2), comma-separated|
|`-i`|Case-insensitive comparison|

## Redirection and Pipelines

Not commands themselves, but essential to using everything above effectively.

bash

```bash
command < file.txt          # feed file as stdin to command
command > file.txt          # write stdout to file (overwrite)
command >> file.txt         # append stdout to file
command 2> file.txt         # redirect stderr to file
command > file.txt 2>&1     # redirect both stdout and stderr to file
command1 | command2         # pipe stdout of command1 into stdin of command2
<(command)                  # process substitution: treat command output as a file
```

**Glossary:**

|Syntax|Meaning|
|---|---|
|`<`|Redirect file to stdin|
|`>`|Redirect stdout to file (creates or overwrites)|
|`>>`|Redirect stdout to file (appends)|
|`2>`|Redirect stderr to file|
|`2>&1`|Redirect stderr to the same place as stdout|
|`\|`|Pipe: connect stdout of left command to stdin of right command|
|`<(cmd)`|Process substitution: run `cmd` and present its output as if it were a file|
