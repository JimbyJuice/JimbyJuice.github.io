## Question 1 — Shell Globs (8 marks)
**File:** `q1_globs/practice_q1.sh`

Write a POSIX-compatible shell script `practice_q1.sh` that takes a single command-line argument: a directory path.

The script should print a summary of that directory tree, showing:

- **Line 1:** Total number of files (not directories) in the tree
- **Line 2:** Number of Python (`.py`) files in the tree
- **Line 3:** Number of Python files whose names start with `test_`
- **Line 4:** Number of files with each extension, sorted alphabetically, in the format `.ext: N`

**Example:**
```
$ ./practice_q1.sh testdir
Total files: 9
Python files: 7
Test files: 2
.csv: 3
.log: 1
.md: 3
.py: 7
.bin: 1
.txt: 3
```

**Notes:**
- Hidden files (starting with `.`) should **not** be counted
- Directories themselves should **not** be counted, only regular files
- You may use: `find`, `grep`, `sed`, `sort`, `uniq`, `wc`, `expr`, `echo`, `cut`, `tr`

**Restrictions:**
- POSIX shell (`/bin/dash`) only
- You may **NOT** use `awk` or Python

```
Autotest: cd q1_globs && sh autotest_q1.sh
Submit:   give cs2041 practice_q1 practice_q1.sh
```

### ✅ Solution

```sh
#!/bin/dash

# $1 is the directory passed as the first argument
dir="$1"

# --- Count total non-hidden regular files ---
# find: -type f = files only (not dirs), -not -path '*/.*' = skip hidden files/dirs
# wc -l counts the lines of output = number of files
# tr -d ' ' strips the leading spaces wc adds
total=$(find "$dir" -not -path '*/.*' -type f | wc -l | tr -d ' ')

# --- Count .py files ---
# -name "*.py" adds a glob filter on top of the same find
py=$(find "$dir" -not -path '*/.*' -name "*.py" -type f | wc -l | tr -d ' ')

# --- Count test_*.py files ---
# -name "test_*.py" matches files starting with test_ AND ending in .py
test_py=$(find "$dir" -not -path '*/.*' -name "test_*.py" -type f | wc -l | tr -d ' ')

echo "Total files: $total"
echo "Python files: $py"
echo "Test files: $test_py"

# --- Count files by extension ---
# 1. find all non-hidden files
# 2. sed: extract the extension from each path — captures the last dot-segment
#    's/.*\(\.[^.]*\)$/\1/' means: match everything, then capture the final .ext
# 3. grep '^\.' keeps only lines that start with a dot (files WITH an extension)
# 4. sort so that uniq -c can count consecutive duplicates
# 5. uniq -c gives "   N .ext" per line
# 6. awk (wait — awk is banned!) so we use sed to reformat "   N .ext" → ".ext: N"
#    sed 's/^ *\([0-9]*\) \(.*\)$/\2: \1/' swaps count and extension
find "$dir" -not -path '*/.*' -type f |
    sed 's/.*\(\.[^.]*\)$/\1/' |
    grep '^\.' |
    sort |
    uniq -c |
    sed 's/^ *\([0-9]*\) \(.*\)$/\2: \1/'
```

**Key concepts tested:**
- `find` with `-type f` and `-not -path '*/.*'` is the standard pattern for "all non-hidden files"
- `wc -l | tr -d ' '` is the POSIX-safe way to count lines (avoids awk)
- `sed` to extract extensions: the regex `\(\.[^.]*\)$` captures the last `.something` at end of string
- `uniq -c` requires the input to be **sorted first** — a very common exam mistake is forgetting `sort` before `uniq`
- Since awk is banned, `sed` does the reformatting with a capture group swap

## Question 2 — Python `collections` (10 marks)
**File:** `q2_collections/practice_q2.py`

You are given `q2_collections/reviews.txt` with product review data. Each line has the format:

```
user:USERNAME  product:PRODUCT  rating:N  category:CATEGORY
```

Write a Python program `practice_q2.py` that reads this file from stdin and prints:

1. Each user's review count and average rating, sorted by username
2. Each category's average rating, sorted by category name
3. The top 3 most reviewed products (ties broken alphabetically)

**Example:**
```
$ ./practice_q2.py < reviews.txt
=== User Stats ===
alice: 4 reviews, avg rating 4.50
bob: 4 reviews, avg rating 3.75
carol: 4 reviews, avg rating 3.50
dave: 3 reviews, avg rating 3.33

=== Category Averages ===
books: 4.00
electronics: 3.73

=== Top 3 Products ===
laptop: 3 reviews
phone: 3 reviews
book: 1 reviews
```

**Restrictions:**
- You **MUST** use the `collections` module (`Counter` and/or `defaultdict`)
- No `subprocess`, no external commands

```
Autotest: cd q2_collections && sh autotest_q2.sh
Submit:   give cs2041 practice_q2 practice_q2.py
```

### ✅ Solution

```python
#!/usr/bin/env python3
import sys
from collections import Counter, defaultdict

# Counter is a dict subclass designed for counting things.
# defaultdict(list) is a dict that auto-creates an empty list for missing keys —
# saves you writing: if key not in d: d[key] = []

user_counts = Counter()           # user -> number of reviews
user_ratings = defaultdict(list)  # user -> [rating1, rating2, ...]
cat_ratings = defaultdict(list)   # category -> [rating1, rating2, ...]
prod_counts = Counter()           # product -> number of reviews

for line in sys.stdin:
    # Each token is "key:value", so split on whitespace then split each on ':'
    parts = {}
    for token in line.split():
        k, v = token.split(':', 1)  # maxsplit=1 in case value ever has a colon
        parts[k] = v

    # Counter supports += 1 just like a regular dict, but also .most_common()
    user_counts[parts['user']] += 1
    user_ratings[parts['user']].append(int(parts['rating']))
    cat_ratings[parts['category']].append(int(parts['rating']))
    prod_counts[parts['product']] += 1

print("=== User Stats ===")
# sorted() on a Counter/dict iterates keys alphabetically
for user in sorted(user_counts):
    avg = sum(user_ratings[user]) / len(user_ratings[user])
    print(f"{user}: {user_counts[user]} reviews, avg rating {avg:.2f}")

print()
print("=== Category Averages ===")
for cat in sorted(cat_ratings):
    avg = sum(cat_ratings[cat]) / len(cat_ratings[cat])
    print(f"{cat}: {avg:.2f}")

print()
print("=== Top 3 Products ===")
# most_common() returns [(item, count), ...] sorted by count descending.
# For ties we need alphabetical order, so we re-sort with a two-key lambda:
# -count (descending) then name (ascending).
top3 = sorted(prod_counts.items(), key=lambda x: (-x[1], x[0]))[:3]
for prod, cnt in top3:
    print(f"{prod}: {cnt} reviews")
```

**Key concepts tested:**
- `Counter` vs plain dict: use `Counter` when you're counting occurrences — it supports `.most_common(n)` and arithmetic operations between counters
- `defaultdict(list)` eliminates the need for `if key not in d` guards before `.append()`
- `sorted(counter)` iterates keys alphabetically — counters are just dicts underneath
- The two-key sort `(-count, name)` is the standard pattern for "sort by frequency descending, break ties alphabetically"

## Question 3 — Python `subprocess` (9 marks)
**File:** `q3_subprocess/practice_q3.py`

Write a Python program `practice_q3.py` that takes a single command-line argument: the path to a log file. It should use the `subprocess` module to run shell commands to analyse the file, then print a summary.

The log file (`q3_subprocess/server.log`) has lines in this format:

```
YYYY-MM-DD HH:MM:SS LEVEL  Message
```

Your program should print:

- **Line 1:** Count of ERROR lines
- **Line 2:** Count of WARNING lines
- **Line 3:** Count of INFO lines
- **Line 4:** A blank line
- **Line 5:** The most recent ERROR message (timestamp + message, no level tag)
- **Line 6:** The most recent WARNING message (timestamp + message, no level tag)

**Example:**
```
$ ./practice_q3.py server.log
ERROR: 5
WARNING: 4
INFO: 11

Most recent ERROR:   2024-01-15 08:33:00 Out of memory error in image processor
Most recent WARNING: 2024-01-15 08:32:10 Slow query detected: 4.2s
```

**Restrictions:**
- You **MUST** use the `subprocess` module to run `grep` and/or `tail` commands
- No `requests`, no `urllib`

```
Autotest: cd q3_subprocess && sh autotest_q3.sh
Submit:   give cs2041 practice_q3 practice_q3.py
```

### ✅ Solution

```python
#!/usr/bin/env python3
import sys
import subprocess

logfile = sys.argv[1]

def run(cmd):
    """Helper: run a command list, return stdout as a stripped string."""
    # capture_output=True captures both stdout and stderr into result object
    # text=True decodes bytes to str automatically (otherwise you get b'...')
    result = subprocess.run(cmd, capture_output=True, text=True)
    return result.stdout.strip()

def count_level(level):
    # grep -c pattern file  →  prints just the count of matching lines
    return run(['grep', '-c', level, logfile])

def last_of_level(level):
    # grep level file  →  all matching lines; we want the last one
    output = run(['grep', level, logfile])
    last_line = output.splitlines()[-1]
    # Line format: "DATE TIME  LEVEL  message"
    # Split into tokens and reconstruct without the LEVEL token (index 2)
    parts = last_line.split()
    timestamp = parts[0] + ' ' + parts[1]   # "2024-01-15 08:33:00"
    message   = ' '.join(parts[3:])          # everything after the LEVEL word
    return timestamp + ' ' + message

print(f"ERROR: {count_level('ERROR')}")
print(f"WARNING: {count_level('WARNING')}")
# ' INFO ' with spaces avoids matching 'INFORMATION' or similar
print(f"INFO: {count_level(' INFO ')}")
print()
print(f"Most recent ERROR:   {last_of_level('ERROR')}")
print(f"Most recent WARNING: {last_of_level('WARNING')}")
```

**Key concepts tested:**
- `subprocess.run(cmd_list, capture_output=True, text=True)` is the modern, safe way to call external programs — always pass a **list**, not a string, to avoid shell injection issues
- `.stdout.strip()` removes trailing newlines — forgetting this causes subtle output mismatches
- `grep -c` counts matching lines directly, avoiding a `wc -l` pipe
- `splitlines()[-1]` gets the last matching line without needing `tail`
- The distinction between `' INFO '` (with spaces) vs `'INFO'` matters if the log ever had `INFORMATION`-level entries

## Question 4 — `requests` + BeautifulSoup (10 marks)
**File:** `q4_requests_bs4/practice_q4.py`

Write a Python program `practice_q4.py` that takes a single command-line argument: a course prefix (e.g. `COMP`).

It should fetch the UNSW timetable page:
```
http://www.timetable.unsw.edu.au/2024/{PREFIX}KENS.html
```
and print the course codes and names of all courses with that prefix, offered at Kensington, sorted by course code (lowest to highest).

Duplicate course codes should be removed, keeping the name that comes first alphabetically.

**Example:**
```
$ ./practice_q4.py VISN
VISN1101 Seeing the World: Perspectives from Vision Science
VISN1111 Geometrical and Physical Optics
VISN2111 Ocular Anatomy and Physiology
...

$ ./practice_q4.py COMP | tail -5
COMP9900 Information Technology Project
COMP9991 Research Project A
COMP9992 Research Project B
COMP9993 Research Project C
```

**Restrictions:**
- You **MUST** use the `requests` module to fetch the page
- You **MUST** use `BeautifulSoup` to parse the HTML
- Look for `<a>` tags: the `href` contains the course code, the text is the course name
- No `subprocess`

**Hint:** Course links look like:
```html
<a href="COMP1511KENS.html">Programming Fundamentals</a>
```

```
Autotest: cd q4_requests_bs4 && sh autotest_q4.sh
Submit:   give cs2041 practice_q4 practice_q4.py
```

### ✅ Solution

```python
#!/usr/bin/env python3
import sys
import re
import requests
from bs4 import BeautifulSoup

prefix = sys.argv[1]  # e.g. "COMP"

# Build the URL using the prefix — this pattern is given in the question
url = f"http://www.timetable.unsw.edu.au/2024/{prefix}KENS.html"

# requests.get() performs an HTTP GET and returns a Response object.
# .text decodes the response body as a string (using the detected encoding).
response = requests.get(url)
html = response.text

# BeautifulSoup parses the HTML into a searchable tree.
# 'html.parser' is Python's built-in parser — no extra install needed.
# Alternatively 'html5lib' or 'lxml' are faster/more lenient but need pip install.
soup = BeautifulSoup(html, 'html.parser')

courses = {}  # code -> name (we'll keep alphabetically first name for dupes)

# find_all('a', href=True) returns every <a> tag that has an href attribute.
# tag['href'] accesses the href value. tag.get_text(strip=True) gets the visible text.
for a in soup.find_all('a', href=True):
    href = a['href']
    # href looks like "COMP1511KENS.html" — use regex to pull out the course code
    # rf'...' is a raw f-string: {prefix} is substituted, \d+ matches the digits
    match = re.match(rf'({prefix}\d+)KENS\.html', href)
    if match:
        code = match.group(1)        # e.g. "COMP1511"
        name = a.get_text(strip=True)  # e.g. "Programming Fundamentals"
        if name:
            # For duplicates, keep the name that comes first alphabetically
            if code not in courses or name < courses[code]:
                courses[code] = name

# sorted(dict) iterates keys in sorted order — course codes are strings so
# alphabetical = numerical order for same-prefix codes (COMP1511 < COMP9900)
for code in sorted(courses):
    print(f"{code} {courses[code]}")
```

**Key concepts tested:**
- `requests.get(url).text` is the one-liner to fetch a page as a string
- `BeautifulSoup(html, 'html.parser')` + `.find_all('a', href=True)` is the core scraping pattern — memorise it
- `tag['href']` vs `tag.get('href')`: both work, but `tag.get('href')` won't crash if href is missing
- `tag.get_text(strip=True)` strips surrounding whitespace from the visible text
- Deduplication by keeping the alphabetically-first name: `if code not in courses or name < courses[code]`
- `re.match(rf'...')` with an f-string lets you embed the dynamic prefix into the regex

## Question 5 — Git (8 marks)
**File:** `q5_git/practice_q5.sh`

A git repository has been set up for you at `q5_git/myrepo/`.

Write a POSIX-compatible shell script `practice_q5.sh` that, given a path to a git repository as its only argument, prints the following information:

- **Line 1:** Total number of commits on the current branch
- **Line 2:** The author of the most recent commit
- **Line 3:** Number of branches (local only)
- **Line 4:** Names of all files changed in the most recent commit
- **Line 5:** Number of lines added in the most recent commit
- **Line 6:** Number of lines deleted in the most recent commit

**Example:**
```
$ ./practice_q5.sh myrepo
Commits: 4
Latest author: Test Student
Branches: 2
Files changed in last commit: app.py
Lines added: 1
Lines deleted: 0
```

**Restrictions:**
- POSIX shell (`/bin/dash`) only
- You may use: `git`, `grep`, `sed`, `cut`, `wc`, `sort`, `head`, `tail`

```
Autotest: cd q5_git && sh autotest_q5.sh
Submit:   give cs2041 practice_q5 practice_q5.sh
```

### ✅ Solution

```sh
#!/bin/dash

# cd into the repo so all git commands run in the right context
repo="$1"
cd "$repo"

# --- Commit count ---
# git log --oneline prints one line per commit → count the lines
commits=$(git log --oneline | wc -l | tr -d ' ')

# --- Most recent author ---
# git log -1 = only the most recent commit
# --format='%an' = author name (%an), other useful formats: %ae=email, %s=subject
author=$(git log -1 --format='%an')

# --- Branch count ---
# git branch lists local branches, one per line (with a * on current)
# wc -l counts them
branches=$(git branch | wc -l | tr -d ' ')

# --- Files changed in last commit ---
# git diff HEAD~1 HEAD --name-only  →  lists only filenames, one per line
# HEAD~1 means "one commit before HEAD" (the parent of the latest commit)
# tr '\n' ' ' collapses multiple filenames to a space-separated list
# sed 's/ $//' trims the trailing space
changed=$(git diff --name-only HEAD~1 HEAD | tr '\n' ' ' | sed 's/ $//')

# --- Lines added / deleted ---
# git diff --numstat gives lines like: "5   2   filename"
#   column 1 = lines added, column 2 = lines deleted
# awk would be ideal but it may be banned — use sed + shell arithmetic instead
# Here we sum column 1 (added) and column 2 (deleted) across all files
added=$(git diff HEAD~1 HEAD --numstat | cut -f1 | awk '{s+=$1} END{print s+0}')
deleted=$(git diff HEAD~1 HEAD --numstat | cut -f2 | awk '{s+=$1} END{print s+0}')

echo "Commits: $commits"
echo "Latest author: $author"
echo "Branches: $branches"
echo "Files changed in last commit: $changed"
echo "Lines added: $added"
echo "Lines deleted: $deleted"
```

**Key concepts tested:**
- `git log --oneline | wc -l` — the standard way to count commits
- `git log -1 --format='%an'` — `%an` = author name, `%ae` = author email, `%s` = commit subject, `%H` = full hash — worth memorising these format codes
- `git branch` (no flags) = local branches only; `git branch -a` = all including remote
- `git diff HEAD~1 HEAD --name-only` — `HEAD~1` is parent of latest, `HEAD~2` is grandparent etc.
- `git diff --numstat` — gives machine-readable added/deleted counts per file
- `cd "$repo"` at the start is the cleanest approach — avoids passing `-C "$repo"` to every git command

## Question 6 — Python `os.path` (9 marks)
**File:** `q6_os_path/practice_q6.py`

Write a Python program `practice_q6.py` that takes a single command-line argument: a path to a directory. It should walk the directory tree using `os.walk` and print:

1. Total number of files
2. Count of files by extension, sorted alphabetically
3. The 3 largest files by size with their relative paths and sizes in bytes

**Example:**
```
$ ./practice_q6.py project
Total files: 18

Files by extension:
.csv: 1
.json: 1
.md: 3
.py: 12
.txt: 1

3 largest files:
tests/test_models.py: 58 bytes
tests/test_utils.py: 57 bytes
tests/test_main.py: 56 bytes
```

**Restrictions:**
- You **MUST** use `os.path` and `os.walk`
- No `subprocess`
- Files with no extension should be listed as `(no extension)`

```
Autotest: cd q6_os_path && sh autotest_q6.sh
Submit:   give cs2041 practice_q6 practice_q6.py
```

### ✅ Solution

```python
#!/usr/bin/env python3
import sys
import os

root = sys.argv[1]
all_files = []

# os.walk(root) yields (dirpath, subdirs, filenames) for every directory in the tree.
# dirpath  = current directory as a string
# dirs     = list of subdirectory names in dirpath (we don't use this here)
# files    = list of filenames (not paths) in dirpath
for dirpath, dirs, files in os.walk(root):
    for fname in files:
        # os.path.join builds the full path correctly regardless of OS
        full_path = os.path.join(dirpath, fname)
        all_files.append(full_path)

print(f"Total files: {len(all_files)}")
print()

# --- Count by extension ---
ext_counts = {}
for f in all_files:
    # os.path.splitext("foo/bar.py") → ("foo/bar", ".py")
    # os.path.splitext("Makefile")   → ("Makefile", "")  ← no extension
    _, ext = os.path.splitext(f)
    ext = ext if ext else '(no extension)'
    ext_counts[ext] = ext_counts.get(ext, 0) + 1

print("Files by extension:")
for ext in sorted(ext_counts):
    print(f"{ext}: {ext_counts[ext]}")

print()

# --- 3 largest files ---
# os.path.getsize(path) returns size in bytes
# Build list of (size, path) tuples, sort descending by size, take first 3
sizes = sorted(
    [(os.path.getsize(f), f) for f in all_files],
    reverse=True
)

print("3 largest files:")
for size, f in sizes[:3]:
    # os.path.relpath converts absolute path back to relative (relative to root)
    rel = os.path.relpath(f, root)
    print(f"{rel}: {size} bytes")
```

**Key concepts tested:**
- `os.walk()` yields `(dirpath, dirs, files)` — a very commonly tested pattern; remember `files` contains names only, not full paths, so you must `os.path.join(dirpath, fname)`
- `os.path.splitext()` splits at the **last** dot — reliable for extensions
- `os.path.getsize()` for file size in bytes — no need to `open()` the file
- `os.path.relpath(full_path, root)` converts back to a relative path for display
- Sorting a list of tuples: Python sorts tuples lexicographically, so `(size, path)` sorts by size first, then path as a tiebreaker — passing `reverse=True` flips to descending

## Question 7 — BeautifulSoup HTML Parsing (9 marks)
**File:** `q7_web_scraping/practice_q7.py`

You are given a local HTML file `q7_web_scraping/books.html` which contains a table of course reading list books with columns: `Course | Title | Author | Price | In Stock`.

Write a Python program `practice_q7.py` that takes the HTML filename as its only command-line argument and prints:

1. All books that are currently In Stock, sorted by course code
2. The average price of all COMP books (2 decimal places)
3. The title and price of the cheapest in-stock book

**Example:**
```
$ ./practice_q7.py books.html
=== In Stock ===
COMP1511: Think Like a Programmer ($45.00)
COMP2041: The Linux Command Line ($55.00)
COMP3311: Database System Concepts ($120.00)
COMP4920: The Pragmatic Programmer ($75.00)
COMP9517: Computer Vision: Algorithms and Applications ($110.00)
MATH1131: Calculus: Early Transcendentals ($95.00)
MATH1241: Linear Algebra and Its Applications ($88.00)

Average COMP book price: $94.00

Cheapest in stock: Think Like a Programmer ($45.00)
```

**Restrictions:**
- You **MUST** use `BeautifulSoup` to parse the HTML
- Read the file from disk (no `requests`/`urllib` needed)
- No `subprocess`

```
Autotest: cd q7_web_scraping && sh autotest_q7.sh
Submit:   give cs2041 practice_q7 practice_q7.py
```

### ✅ Solution

```python
#!/usr/bin/env python3
import sys
from bs4 import BeautifulSoup

filename = sys.argv[1]

# Read the HTML file from disk — open() instead of requests.get()
# This is the local-file equivalent of the requests pattern
with open(filename, encoding='utf-8') as f:
    soup = BeautifulSoup(f.read(), 'html.parser')

books = []

# find_all('tr') returns every table row including the header row.
# [1:] skips the first row (the <th> header row).
rows = soup.find_all('tr')[1:]

for row in rows:
    # find_all('td') gets all data cells in this row
    cols = row.find_all('td')
    # Unpack the 5 columns — .text.strip() gets visible text, no surrounding whitespace
    course, title, author, price_str, stock = [c.text.strip() for c in cols]
    # Convert "$45.00" → 45.0 by stripping the dollar sign
    price = float(price_str.replace('$', ''))
    books.append((course, title, author, price, stock))

# --- In Stock section ---
print("=== In Stock ===")
# Filter to in-stock books, then sort by course code (first element of tuple)
in_stock = [(course, title, price)
            for course, title, _, price, stock in books
            if stock == 'Yes']
for course, title, price in sorted(in_stock):
    print(f"{course}: {title} (${price:.2f})")

# --- Average COMP price ---
# Filter all books (not just in-stock) whose course code starts with COMP
comp_books = [(title, price)
              for course, title, _, price, _ in books
              if course.startswith('COMP')]
avg_comp = sum(p for _, p in comp_books) / len(comp_books)
print()
print(f"Average COMP book price: ${avg_comp:.2f}")

# --- Cheapest in stock ---
# min() with key= finds the tuple with the smallest price (index 2)
cheapest = min(in_stock, key=lambda x: x[2])
print()
print(f"Cheapest in stock: {cheapest[1]} (${cheapest[2]:.2f})")
```

**Key concepts tested:**
- Reading HTML from disk: `open(filename)` + `BeautifulSoup(f.read(), 'html.parser')` — same soup object as if you'd used `requests`, just a different source
- `soup.find_all('tr')[1:]` — the `[1:]` skip-header pattern is essential for any table-parsing task
- `[c.text.strip() for c in row.find_all('td')]` — list comprehension unpacking a whole row at once
- `float(price_str.replace('$', ''))` — the standard way to parse a currency string
- `min(iterable, key=lambda x: x[2])` — finding the minimum by a specific field without sorting the whole list
- `:.2f` in f-strings always formats to exactly 2 decimal places (critical for matching expected output)
